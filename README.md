# FloodSafe-IoT
Sistema IoT de monitoreo y alertas de nivel de agua

FloodSafe es un proyecto de Internet de las Cosas (IoT) que desarrollamos para monitorear el nivel de agua en cisternas o depósitos y ayudar a prevenir desbordamientos y desperdicios de agua.

Para construirlo utilizamos una Raspberry Pi 4, un sensor ultrasónico JSN-SR04T, tres luces LED y un buzzer. El sistema mide la distancia hasta el agua y utiliza tres niveles de alerta: verde (normal), amarillo (advertencia) y rojo (crítico).

También creamos una página web utilizando Python y Flask para visualizar las mediciones y conocer el estado del agua. Nuestro objetivo es ofrecer una solución sencilla que pueda ser útil en hogares y pequeños negocios.
